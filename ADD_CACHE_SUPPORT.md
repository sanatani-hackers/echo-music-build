# ADD_CACHE_SUPPORT.md - Echo Music Offline Stream Caching Architecture & Plan

## 1. Goal
Add robust, seamless offline playback and cache awareness to **Echo Music** so that songs streamed during normal listening are automatically cached locally and can be played back seamlessly without an internet connection, even after app restarts.

---

## 2. Architectural Analysis: Current State vs Target State

### Current State
1. **Cache Singletons Already Exist**:
   - In [`AppModule.kt`](app/src/main/kotlin/com/music/echo/di/AppModule.kt), Hilt already provides two `androidx.media3.datasource.cache.SimpleCache` instances:
     - `@PlayerCache`: Backed by directory `context.filesDir.resolve("exoplayer")`, configured with `DynamicLruCacheEvictor` respecting `MaxSongCacheSizeKey`.
     - `@DownloadCache`: Backed by directory `context.filesDir.resolve("download")`, configured with `NoOpCacheEvictor`.
     - Both use `androidx.media3.database.StandaloneDatabaseProvider`.
2. **Current Caching Pipeline in `MusicService.kt`**:
   - `createCacheDataSource()` wraps OkHttp with a two-tiered `CacheDataSource.Factory`:
     - Outer: `downloadCache` (read-only sink: `setCacheWriteDataSinkFactory(null)`).
     - Inner: `playerCache` (read-write default sink).
   - Chunks streamed during normal playback *are* written to `playerCache`.
3. **The Offline Playback Bug/Gap**:
   - When offline, `createDataSourceFactory()` in `MusicService.kt` checks:
     ```kotlin
     val isFullyDownloaded = (cachedLength > 0 && downloadCache.isCached(mediaId, 0, cachedLength)) ||
       (dbSong?.song?.isDownloaded == true && downloadCache.getCachedSpans(mediaId).isNotEmpty())
     ```
   - Notice it **only** checks `downloadCache`.
   - If the song is only in `playerCache`, the service checks `cachedStream` (`songUrlCache`). But `songUrlCache` is an ephemeral in-memory map with short expiry (~1-6 hours) and is wiped on process death.
   - When `cachedStream` is null or expired, the service tries to fetch fresh streaming URLs from `YTPlayerUtils.playerResponseForPlayback(videoId = mediaId, ...)`, which fails with network error when offline.
   - Result: Tracks 100% cached in `playerCache` fail to play offline!
4. **Key Mechanism (Cache Keys)**:
   - In Echo Music, cache keys are indexed by **`mediaId`** (song ID, e.g. YouTube video ID), **not** by raw streaming URLs. Streaming URLs generated by YouTube InnerTube are transient, signed, and expire within hours. Using `mediaId` ensures cache hits regardless of URL changes.

## 4. Detailed Component Design

### 1️⃣ `CacheUtil.kt`
```kotlin
package echo.music.iad1tya.playback

import androidx.media3.datasource.cache.ContentMetadata
import androidx.media3.datasource.cache.SimpleCache
import echo.music.iad1tya.db.MusicDatabase
import echo.music.iad1tya.di.DownloadCache
import echo.music.iad1tya.di.PlayerCache
import javax.inject.Inject
import javax.inject.Singleton
import kotlinx.coroutines.flow.firstOrNull

@Singleton
class CacheUtil @Inject constructor(
    @PlayerCache private val playerCache: SimpleCache,
    @DownloadCache private val downloadCache: SimpleCache,
    private val database: MusicDatabase
) {
    /**
     * Checks if a mediaId is fully cached in either playerCache or downloadCache.
     */
    suspend fun isFullyCached(mediaId: String): Boolean {
        val contentLength = getContentLength(mediaId)
        if (contentLength > 0) {
            if (downloadCache.isCached(mediaId, 0, contentLength)) return true
            if (playerCache.isCached(mediaId, 0, contentLength)) return true
        } else {
            // If length is unknown, check if spans exist
            if (downloadCache.getCachedSpans(mediaId).isNotEmpty()) return true
            if (playerCache.getCachedSpans(mediaId).isNotEmpty()) return true
        }
        return false
    }

    /**
     * Synchronous check if contentLength is already available.
     */
    fun isFullyCachedSync(mediaId: String, contentLength: Long?): Boolean {
        if (contentLength != null && contentLength > 0) {
            return downloadCache.isCached(mediaId, 0, contentLength) ||
                   playerCache.isCached(mediaId, 0, contentLength)
        }
        return downloadCache.getCachedSpans(mediaId).isNotEmpty() ||
               playerCache.getCachedSpans(mediaId).isNotEmpty()
    }

    /**
     * Returns total cached bytes across player and download caches for a media item.
     */
    fun getCachedBytes(mediaId: String): Long {
        val downloadBytes = downloadCache.getCachedSpans(mediaId).sumOf { it.length }
        val playerBytes = playerCache.getCachedSpans(mediaId).sumOf { it.length }
        return downloadBytes + playerBytes
    }

    /**
     * Look up contentLength from metadata or database format.
     */
    private suspend fun getContentLength(mediaId: String): Long {
        val downloadMeta = ContentMetadata.getContentLength(downloadCache.getContentMetadata(mediaId))
        if (downloadMeta > 0) return downloadMeta

        val playerMeta = ContentMetadata.getContentLength(playerCache.getContentMetadata(mediaId))
        if (playerMeta > 0) return playerMeta

        val dbFormat = database.format(mediaId).firstOrNull()
        return dbFormat?.contentLength ?: -1L
    }

    /**
     * Removes song from playerCache.
     */
    fun removeFromPlayerCache(mediaId: String) {
        playerCache.removeResource(mediaId)
    }
}
```

### 2️⃣ `MusicService.kt` Resolution Update
In `createDataSourceFactory()`:
```kotlin
val cachedLength =
  androidx.media3.datasource.cache.ContentMetadata.getContentLength(
      downloadCache.getContentMetadata(mediaId)
    ).takeIf { it != androidx.media3.common.C.LENGTH_UNSET.toLong() }
    ?: androidx.media3.datasource.cache.ContentMetadata.getContentLength(
      playerCache.getContentMetadata(mediaId)
    ).takeIf { it != androidx.media3.common.C.LENGTH_UNSET.toLong() }
    ?: dbFormat?.contentLength
    ?: -1L

val isFullyInDownloadCache =
  (cachedLength > 0 && downloadCache.isCached(mediaId, 0, cachedLength)) ||
  (dbSong?.song?.isDownloaded == true && downloadCache.getCachedSpans(mediaId).isNotEmpty())

val isFullyInPlayerCache =
  cachedLength > 0 && playerCache.isCached(mediaId, 0, cachedLength)

val isPlayableOffline = isFullyInDownloadCache || isFullyInPlayerCache
```
If `isPlayableOffline`, the dataSource returns `dataSpec` directly with a safe fallback URI so Media3 serves data straight from the cache without requiring a network call.

### 3️⃣ UI Badging & Controls
- In `SongListItem`, display `Icon.Cached()` (`R.drawable.cached`) when a song is cached in `playerCache` and not yet fully downloaded.
- In `StorageSettings.kt`, provide dynamic ceiling management: an Unlimited toggle (`-1`) and a 100 MB to 10 GB slider that immediately adjusts `DynamicLruCacheEvictor` without restarting the playback service.
